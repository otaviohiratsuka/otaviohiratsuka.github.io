Desafio Inovamobil

O desafio técnico consistiu no desenvolvimento do back-end de uma Plataforma Bancária transacional, desenhada para simular operações financeiras seguras, como abertura de contas empresariais (com validação via integração externa), depósitos, saques, transferências e emissão de extratos.
