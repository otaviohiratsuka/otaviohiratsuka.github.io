Futepong

O FutePong é um jogo 2D voltado para dois jogadores locais. A proposta é uma releitura do clássico jogo Pong adaptada para o tema de futebol, na qual cada jogador assume o controle de um "goleiro" com o objetivo de marcar gols no adversário.
