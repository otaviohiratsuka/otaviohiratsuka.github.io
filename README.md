# Meu Portfólio Pessoal 🚀

Bem-vindo ao repositório do meu portfólio! Este projeto foi desenvolvido para apresentar minha trajetória profissional, formação acadêmica e os principais projetos em que venho trabalhando.

🌍 **Acesse o site online:** [otaviohiratsuka.github.io](https://otaviohiratsuka.github.io)

## 🛠️ Tecnologias Utilizadas

O site foi construído do zero focando em performance e design moderno, utilizando:
* **Angular** (Framework principal e roteamento)
* **Tailwind CSS** (Estilização e responsividade)
* **TypeScript** & **HTML5**
* **AOS (Animate On Scroll)** (Animações de interface)
* **Devicon** (Biblioteca de ícones)
